## Description
auto-tests checking the correctness of the API method for creating a favorite place.

## Setup

### ✅ Prerequisites

- [Python](https://www.python.org/) (3.11+ recommended)
- [uv](https://docs.astral.sh/uv/getting-started/installation/)

1. Clone the repository and install dependencies
    ```bash
    git clone https://github.com/maximSytd/2gis-QA-test.git &&
    cd 2gis-QA-test && uv sync --active
    ```

2. Run tests
    ```shell
    pytest
    ```
